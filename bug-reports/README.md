## Defect Documentation Standard

Each report records:

- Summary
- Status/classification
- Severity and priority where applicable
- Preconditions
- Reproduction steps
- Expected result
- Actual result
- Impact
- Evidence/reference information

Payment-related evidence should be redacted before being committed to a public repository. Never publish full payment-card numbers.
